# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

People managing changing personal and professional work who need Novo to retain
context between sessions instead of repeatedly reconstructing it in prompts.

## Product Purpose

Novo is a Cognitive Adaptive Application. It maintains a persistent,
correctable model of the user's operating context so recommendations, actions,
and explanations become more useful as outcomes accumulate.

## Positioning

The Cognitive Twin is shared by Today, Cognitive, Chat, Activity, and actions.
It distinguishes evidence from inference, accepts corrections, and only adapts
its behavior when real signals or outcomes warrant it.

## Operating Context

The user moves between planning, focus, chat, activity, and cognitive-review
surfaces. The product loop is Observe, Understand, Propose, Act with
permission, Verify, Learn, and Adapt.

## Capabilities and Constraints

- Next.js App Router, React, TypeScript, Prisma, and authenticated API routes.
- The graph must be evidence-backed, correctable, and owner-scoped.
- Actions that affect external systems remain proposal-only until confirmation.
- The 3D graph is progressive enhancement: the same learning must remain
  understandable and operable without WebGL or pointer interaction.

## Brand Commitments

Novo communicates calm, inspectable shared understanding rather than hidden
automation or clinical claims. The Cognitive Twin is an operating model, not a
diagnosis.

## Evidence on Hand

- Cognitive thesis: `docs/novo-cognitive-product-thesis.md`.
- Existing cognitive graph projection and command surface.
- Twin evolution logs, signal ledger, recommendations, outcomes, and persisted
  adaptation policy are the available sources of graph truth.

## Product Principles

- Learning is visible only when it can be traced to evidence or an explicit
  correction.
- A new learning must change a future recommendation, explanation, or behavior.
- The interface leads with the user's next useful action, not a decorative map.
- Every inference can be inspected, corrected, or excluded when applicable.

## Accessibility & Inclusion

Keyboard and screen-reader users receive the same learning summary, evidence,
and corrective controls as users of the visual graph.
