# Demo SaaS explainer de Novo

Duración objetivo: 75 a 90 segundos. Formato: 16:9 para web y 9:16 recortable para redes. El mensaje debe mostrar acciones reales de la aplicación, no promesas de diagnóstico personal.

## Guion

| Tiempo | Imagen | Locución / texto en pantalla |
| --- | --- | --- |
| 0-06 s | Landing y el escritorio de Novo. | **“Tu día no necesita más ruido. Necesita una siguiente acción clara.”** |
| 06-18 s | Crear un objetivo y completar el check-in de estado. | “Novo parte de tu objetivo, el tiempo disponible y el contexto que tú indicas.” |
| 18-34 s | Nuevo ciclo: actividad, hechos, estimación y recomendación. Abrir “Por qué aparece esta recomendación”. | “La recomendación separa los hechos observados de la estimación. Puedes revisar qué la respalda antes de actuar.” |
| 34-48 s | Aceptar, iniciar y completar una acción. Mostrar feedback útil/no útil. | “Acepta, ajusta o pospone. El resultado queda registrado para que el próximo plan aprenda de lo que te funciona.” |
| 48-61 s | Abrir Calendar, elegir `Programar enfoque` y mostrar la confirmación. | “Las acciones externas siempre esperan tu confirmación. Nada se crea en tu calendario por sorpresa.” |
| 61-75 s | Checklist priorizado, Hub y cierre en landing. | **“Menos listas infinitas. Más progreso verificable.”** Prueba Novo hoy. |

## Preparación de captura

1. Usar una cuenta de demostración con objetivos y tareas sintéticos. No grabar nombres, notas, tokens, calendario ni datos de personas reales.
2. Preparar una tarea de pago o lanzamiento, un check-in de 45 minutos y una recomendación en estado `proposed`.
3. Ensayar el flujo completo: objetivo → check-in → plan → aceptar → iniciar → completar → marcar útil → siguiente plan.
4. Tener Calendar conectado sólo a una agenda de demo. Grabar la tarjeta de confirmación antes de crear el bloque y, si se muestra el resultado, usar un evento de prueba.
5. Activar tema oscuro, animaciones normales y resolución 1440×900. Capturar también una toma vertical a 390×844 para el recorte de redes.
6. Silenciar notificaciones del sistema y usar datos visuales legibles. Comprobar contraste del texto sobre el wallpaper antes de grabar.

## Entregables

- Vídeo maestro 16:9 de hasta 90 segundos, subtitulado en español.
- Recorte 9:16 de 45 a 60 segundos, con el mismo mensaje principal.
- Miniatura: “Tu siguiente acción, con evidencia”.
- Pantalla final con ruta pública, plan de prueba y contacto de soporte.
